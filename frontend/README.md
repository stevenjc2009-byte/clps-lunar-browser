# CLPS Lunar Mission Browser: web front end

React + TypeScript + Vite + Plotly. It reads `public/sky.json`, which `../backend/compute.py` writes.

```
npm install
npm run dev     # http://localhost:5173
npm run build   # static site in dist/
```

The project overview, data sources, validation, SI-use statement and references are in [../README.md](../README.md).
